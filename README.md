# Kodi Lyrion

Control a Lyrion Music Server (formerly Logitech Media Server) player from
Kodi. The full-screen interface shows the playing track and album art, playback
position, and a playlist you can browse and play from. Use the on-screen,
keyboard, or remote controls for previous, next, play/pause, repeat, and
shuffle. The add-on discovers Lyrion servers on your local network
automatically.

## Install

1. Download the latest `plugin.audio.lyrion-*-kodi21.zip` from the
   [GitHub Releases](https://github.com/itsonlyaudio/Kodi-Lyrion-Control/releases/latest)
   page.
2. In Kodi, choose **Add-ons → Install from zip file** and select the ZIP.
3. Open **Lyrion** from your add-ons. If server discovery does not find your
   server, enter its address in the add-on settings.
